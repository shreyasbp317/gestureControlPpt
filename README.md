# 🎯 Gesture-Controlled Presentation Tool

Control your PowerPoint, PDF, or browser-based presentations using simple **hand gestures**! This Python app uses **MediaPipe**, **OpenCV**, and **PyAutoGUI** to detect hand gestures like pinching or spreading fingers to navigate slides.

---

## 🚀 Features

- 👆 Pinch (thumb + index finger) → Next Slide
- ✋ Fingers apart (thumb and index far) → Previous Slide
- 🧠 Gesture stability + cooldown logic → Prevents accidental slides
- 🎥 Real-time video feedback with landmark tracking
- 🖥️ GUI built with Tkinter to start/stop gesture control
